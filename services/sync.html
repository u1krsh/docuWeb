Offline-First Sync Engine Specification

Git-like Synchronization Model
MotorMeasure Pro's sync architecture follows a commit locally, push when online paradigm implemented in src/gmfm_app/services/sync_service.py.
Document Contents
  • 1. The Mutation Queue (sync_queue)
  • 2. Push Engine (Local → Cloud)
  • 3. Pull Engine & Conflict Resolution
  • 4. Background SyncWorker Poller

1. The Mutation Queue (sync_queue)

Every clinical transaction (adding a student, recording a GMFM session, editing patient info, or deleting records) writes an entry into the local sync_queue table within the same SQLite transaction. The payload contains the full serialized state of the entity.

2. Push Engine (Local → Cloud)

The push routine batches up to 100 unsynced queue items per cycle:

  • Ensures valid cloud authentication (restoring session from ~/.gmfm_app/.cloud_token if necessary).
  • Translates local primary keys into cloud records indexed by composite unique key: (created_by, local_id).
  • For DELETE operations, issues a soft-delete tombstone (deleted: true) to prevent data loss across peer devices.
  • Upon successful HTTP 200 response from Supabase, marks synced = 1 in sync_queue.

3. Pull Engine & Conflict Resolution

Conflict Resolution Strategy: Local Wins
Before applying any incoming cloud mutation into local SQLite, the pull routine executes: SELECT COUNT(*) FROM sync_queue WHERE table_name = ? AND record_id = ? AND synced = 0. If a pending local mutation exists, the incoming cloud update is discarded.

This guarantees that a clinician's active on-device edits are never overwritten by stale cloud data arriving after network reconnection.

4. Background SyncWorker Poller

SyncWorker is a daemon thread instantiated during application bootstrap. It operates on a 60-second cycle:

src/gmfm_app/services/sync_worker.pyBackground Loop
def _run_loop(self):
    time.sleep(5) # Initial warmup delay
    while self._running:
        try:
            if not self.sync_service.is_online():
                _log("Offline — skipping sync cycle")
            else:
                self._provision_pending_accounts()
                pending = self.sync_service.get_pending_count()
                if self.sync_service.ensure_auth():
                    if pending > 0:
                        res = self.sync_service.sync()
                    else:
                        res = self.sync_service.pull()
        except Exception as e:
            _log(f"Auto-sync error: {e}")

        # Sleep in 1s increments for responsive shutdown
        for _ in range(self.interval):
            if not self._running: break
            time.sleep(1)
