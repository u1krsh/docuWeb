Clinical Report Generation & 3-Tier PDF Pipeline

Universal PDF Generation
Medical assessment tools require deterministic PDF scoresheets that match official clinical standards. ReportService implements a 3-tier fallback engine ensuring valid PDF generation on any OS without crashing.
Document Contents
  • 1. The Three PDF Generation Tiers
  • 2. The Zero-Dependency Raw PDF Engine
  • 3. Clinical Scoresheet Content Specification

1. The Three PDF Generation Tiers

TierBackendDependency TypePlatform Suitability
Tier 1 ReportLab Compiled C-Extensions Desktop (Windows, macOS, Linux). Full vector layout with embedded Matplotlib trend charts.
Tier 2 fpdf2 Pure Python Library Android mobile runtime where C-extensions may not load cleanly.
Tier 3 Raw PDF Generator Zero Dependencies (Python stdlib) Universal safety net. Generates valid PDF 1.4 byte streams using raw postscript operators.

2. The Zero-Dependency Raw PDF Engine

To eliminate failure points on stripped embedded runtimes, ReportService implements _PdfPage and _write_pdf_pages() (~300 lines of pure Python code):

  • Constructs raw PDF graphics streams (re, rg, RG, w, m, l, S, B) for bordered tables and colored score banners.
  • Implements character-width proportional text rendering for standard Helvetica and Helvetica-Bold Type1 fonts.
  • Builds genuine multi-page documents with automatic page breaks, repeated column headers, cross-reference tables (xref), and catalog trailers.

3. Clinical Scoresheet Content Specification

All three backends produce clinically equivalent output containing:

  1. Official Header: Gross Motor Function Measure (GMFM) Scoresheet.
  2. Student Demographics: Full decrypted name, Medical Record Number (MRN), Date of Birth, and Assessment Date.
  3. Assessor Details: Tested by clinician name (resolved from app_users).
  4. Total Score Banner: Highlighted primary teal banner displaying the overall percentage.
  5. Domain Summary Table: Dimensions A through E with percent score and items tested ratio (e.g. 17/17).
  6. Detailed Item Breakdown: Full tabular list of all 88 items marked with X under columns 0, 1, 2, 3, or NT.
  7. Clinical Notes: Multi-line qualitative observational remarks.
