Services Subsystem Overview

Business Logic Layer
The Services Subsystem (src/gmfm_app/services/) comprises 12 modular services implementing authentication, cloud synchronization, report generation, role authorization, and device hardware abstractions.
Document Contents
  • 1. Services Directory Map
  • 2. Detailed Subsystem Manuals

1. Services Directory Map

ServiceModule FileLinesCore Functionality
AuthService auth_service.py 437 Local PBKDF2 authentication, Supabase cloud registration/login, OTP password recovery.
SyncService sync_service.py 683 Push/pull offline-first synchronization engine communicating with Supabase PostgREST.
SyncWorker sync_worker.py 146 Background polling daemon (60s loop) checking network reachability and flushing queues.
ReportService report_service.py 650 Multi-tier PDF clinical report builder (ReportLab → fpdf2 → raw PDF byte engine).
AccessService access_service.py 83 Resolves AccessScope boundaries for Admin, Teacher, Parent, and Sponsor roles.
ChartService chart_service.py 94 Matplotlib longitudinal trend plotting rendered to PNG byte buffers for UI and PDFs.
SecurityProvider security.py 91 Fernet AES-128-CBC encryption key resolution and symmetric encryption helpers.
DocxImportService docx_import_service.py 324 Parses legacy GMFM Word assessment documents (.docx) into structured student sessions.
Haptics haptics.py 82 Tactile vibration patterns optimized for mobile devices (Nothing Phone 2a linear motor).
InstructionsService instructions_service.py 100 Loads exercise descriptions and starting positions from embedded JSON data.
UIScale ui_scale.py 125 Reads Android system text_scale_factor and dynamically scales UI container metrics.
