Device Hardware Services & DOCX Importer

Platform Integration
MotorMeasure Pro provides specialized device integration services including customized mobile haptics, Android display scaling, and legacy document import.
Document Contents
  • 1. Tactile Haptic Feedback (haptics.py)
  • 2. Android Accessibility Scaling (ui_scale.py)
  • 3. DOCX Assessment Importer (docx_import_service.py)

1. Tactile Haptic Feedback (haptics.py)

To assist therapists during fast-paced clinical assessments with active children, the UI provides instant tactile confirmation when rating buttons are tapped. The haptic service is calibrated for mobile linear resonant actuators (notably Nothing Phone 2a):

  • Haptics.light(): 15ms light pulse on item selection.
  • Haptics.medium(): 30ms pulse on domain navigation tab switch.
  • Haptics.heavy(): 50ms pulse on session submission and report generation.
  • Haptics.success(): Double-tap pattern (20ms pulse, 40ms pause, 20ms pulse) on cloud sync completion.

2. Android Accessibility Scaling (ui_scale.py)

On Android devices, users may configure system-wide accessibility display scaling or enlarged font sizes. Standard GUI layouts frequently clip or overflow when text scales up. apply_android_scale() inspects the system page.client_storage or platform metrics, computing a responsive scale multiplier and dynamically adapting container paddings, font sizes, and button heights.

3. DOCX Assessment Importer (docx_import_service.py)

Clinics transitioning from paper or Word-based assessments can directly import legacy evaluations. The importer:

  • Parses table structures from Microsoft Word (.docx) documents using python-docx.
  • Extracts student metadata (Name, DOB, Date of Assessment, Assessor).
  • Parses multi-column scoresheets, recognizing numerical scores 0–3 while discarding 'NT' marks.
  • Supports multi-session documents with multiple date headers, creating longitudinal session records in local SQLite.
