Screen Inventory & Clinical Navigation Flow

This manual provides an exhaustive inventory of the 10 application screens, detailing their layout, user interactions, and permission scopes.

1. LoginView (/login)

Handles local and cloud authentication. Features:

  • Username and password input fields with input normalization.
  • First-time administrator setup banner when no accounts exist.
  • Tab toggle between Sign In, Register New Account, and Forgot Password.
  • Role selection during registration: Teacher, Parent, or Admin.

2. DashboardView (/)

The primary clinical command center for therapists and administrators:

  • Header Metrics: Displays total active students, total completed assessments, and institutional average score.
  • Search Bar: Instant client-side filtering by child name or medical record number.
  • Student Cards: Each card displays child demographics, latest GMFM score badge, assessment date, and quick action buttons (Start Test, View History, Edit Profile).
  • Floating Action Button (FAB): Prominent shortcut to register a new student.

3. ScoringView (/scoring)

The core clinical evaluation interface:

  • Domain Selector Tabs: Horizontal scrollable tab bar switching between Dimensions A, B, C, D, and E with real-time domain completion percentages.
  • Item Cards: Displays item number, official instruction text, and 5 interactive rating pills: 0, 1, 2, 3, and NT.
  • In-App Exercise Instructions: An expandable drawer showing starting posture, clinical task description, and scoring guidance.
  • Haptic Feedback: Instant tactile vibration pulse on score selection.
  • Save & Generate Report: Validates scoring, executes scoring calculation, persists to SQLite, and launches PDF generation dialog.

4. StudentView (/student)

Profile editor for registering or updating patient records. Encapsulates form fields for Given Name, Family Name, Date of Birth (with interactive date picker), and Medical Record Identifier.

5. SessionHistoryView & SessionDetailView

  • History View: Renders a longitudinal chronological timeline of all evaluations for a child, complete with overall score progression and notes summary.
  • Detail View: Displays the full post-assessment report on-screen, including domain radar/bar graphs, item-by-item ratings, assessor identity, and PDF export buttons.

6. CompareView (/compare)

Enables therapists to select any two assessment dates and render a side-by-side comparative table showing point differences, percentage changes per domain, and developmental progress.

7. SettingsView (/settings)

Administrative configuration center:

  • Dark mode / Light mode toggle.
  • Supabase Cloud Sync configuration (URL, anon key, connection status badge).
  • Manual "Sync Now" button and pending queue counter.
  • Microsoft Word (DOCX) assessment importer.
  • Sign out action.

8. AdminConsoleView (/admin)

Restricted to administrators. Lists all system users, account active status, role modification dropdowns, and user creation forms.

9. ParentDashboardView (/ - Parent Role)

Dedicated read-only portal for parents. Shows a simplified progress summary of their linked child, domain improvement badges, and historical assessment reports without clinical administrative clutter.
