Presentation Architecture & Flet Framework

Native UI Rendering
MotorMeasure Pro's graphical interface is built using Flet (version 0.28.3). Flet translates high-level Python declarative component trees into native Flutter widgets, achieving 60 FPS touch responsiveness on mobile hardware.

1. Views-Based Declarative Routing

The application avoids monolithic canvas redraws. Instead, each screen implements a factory method returning an independent ft.View:

src/gmfm_app/main.pyRoute Dispatcher
def _create_view(self, route: str):
    is_dark = self.page.theme_mode == ft.ThemeMode.DARK
    current_user = self.auth_service.current_user(self.page)
    scope = AccessService(self.db_context).scope_for(current_user)

    if route == "/":
        return DashboardView(self.page, self.db_context, is_dark, current_user=current_user, ...)
    elif route.startswith("/scoring"):
        pid = self._param_from_route(route, "student_id")
        return ScoringView(self.page, self.db_context, int(pid), is_dark=is_dark, ...)
    elif route.startswith("/admin"):
        return AdminConsoleView(self.page, self.db_context, is_dark, ...)

2. Role-Based Route Guards

Before any view is instantiated, _create_view() evaluates the authenticated role:

  • /admin* routes immediately check user_role == 'admin'. Non-administrators receive an Access Denied view.
  • sponsor roles are locked strictly to / (aggregate dashboard view).
  • parent roles are permitted to view /, /session, and /history, but are blocked from scoring routes.
