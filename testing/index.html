Test Suite, Unit Verification & Clinical Oracle

Verification Strategy
The automated test suite in tests/ verifies the mathematical fidelity of scoring calculations, missing-item exclusion rules, and document parsing integrity.
Document Contents
  • 1. Running the Automated Test Suite
  • 2. Scoring Engine Unit Tests (test_scoring.py)
  • 3. Document Importer Tests (test_docx_import_verify.py)

1. Running the Automated Test Suite

TerminalPytest Invocation
# Run complete test suite with verbose output
python -m pytest tests/ -v

# Or using standard library unittest runner
python -m unittest discover -s tests -p "test_*.py"

2. Scoring Engine Unit Tests (test_scoring.py)

Verifies boundary calculations against canonical GMFM oracles:

  • All-Maximum Boundary Test: Asserts that an assessment with all 88 items scored 3 yields exactly 100.0% across all domains and total.
  • All-Zero Boundary Test: Asserts that an assessment with all items scored 0 yields exactly 0.0%.
  • Partial Scoring Oracle Test: Verifies that omitted items are excluded from the denominator rather than counted as 0 points.
  • Clamping Test: Passes out-of-range ratings (e.g. -5, 10) and verifies that the engine defensively clamps to the interval [0, 3].

3. Document Importer Tests (test_docx_import_verify.py)

Executes an end-to-end import test using an in-memory SQLite database, verifying table extraction, metadata parsing, and accurate exclusion of 'NT' rows.
