Layered Architecture Specification

MotorMeasure Pro enforces a strict separation of concerns through four core layers. Inter-layer communication is unidirectional: outer presentation components depend on inner services and models, while domain calculation logic remains completely isolated.

  • 2. Services Layer (Business Logic)
  • 3. Scoring Engine (Domain Logic)

1. Presentation Layer (Views)

The presentation layer is located in src/gmfm_app/views/. Unlike traditional desktop GUI toolkits that mutate global canvases, MotorMeasure Pro uses Flet's views-based routing pattern.

Each screen is constructed as an independent class or factory that returns an instance of flet.View. The top-level GMFMApp controller manages the route stack:

gmfm_app/main.pyRoute Navigation Handler
def _handle_route(self, is_back=False):
    current_route = self.page.route or "/"
    is_public = current_route.startswith("/login")
    is_authenticated = self.auth_service.is_authenticated(self.page)

    # 1. Gate unauthenticated requests
    if not is_authenticated and not is_public:
        self.page.go("/login")
        return

    # 2. Redirect authenticated users hitting login back to dashboard
    if is_authenticated and is_public:
        self.page.go("/")
        return

    # 3. Stack management
    if is_back:
        if len(self.page.views) > 1:
            self.page.views.pop()
    else:
        new_view = self._create_scaled_view(current_route)
        if new_view:
            self.page.views.append(new_view)
    self.page.update()

2. Services Layer (Business Logic)

Located in src/gmfm_app/services/, this layer houses all business operations:

  • AuthService: Manages local account creation, PBKDF2 password verification, token persistence in Flet client_storage, and auto-provisioning against Supabase GoTrue.
  • AccessService: Determines exact data visibility scopes (AccessScope) based on the user's role (admin, teacher, parent, sponsor).
  • SyncService & SyncWorker: Asynchronously manages cloud synchronization without freezing the UI thread.
  • ReportService: Coordinates PDF scoresheet output across 3 diverse rendering engines.
  • ChartService: Renders longitudinal motor trajectory trend charts using Matplotlib into in-memory PNG byte buffers.
  • SecurityProvider: Resolves Fernet encryption keys and provides symmetric cipher helpers for patient PII fields.

3. Scoring Engine (Domain Logic)

Located in src/gmfm_app/scoring/, the clinical scoring engine has zero dependencies on databases or UI widgets. It takes raw scores as input and produces mathematical domain percentages:

gmfm_app/scoring/engine.pyPure Scoring Engine Logic
def calculate_gmfm_scores(raw_scores: Dict[int, int], scale: str = "88") -> Dict[str, object]:
    items_map = GMFM88_ITEMS
    domains = {}
    total_score = 0.0
    total_items_scored = 0
    total_items = 0

    for domain, item_ids in items_map.items():
        percent, n_items_scored = _score_domain(item_ids, raw_scores)
        domains[domain] = {
            "percent": round(percent, 2),
            "n_items_scored": n_items_scored,
            "n_items_total": len(item_ids)
        }
        total_items_scored += n_items_scored
        total_items += len(item_ids)
        total_score += (percent / 100.0) * (len(item_ids) * MAX_ITEM_SCORE)

    max_possible_all = total_items * MAX_ITEM_SCORE if total_items > 0 else 1
    total_percent = (total_score / max_possible_all) * 100.0

    return {
        "scale": scale,
        "domains": domains,
        "total_percent": round(total_percent, 2),
        "items_scored": total_items_scored,
        "items_total": total_items,
    }

4. Data Layer (Persistence & Security)

Located in src/gmfm_app/data/, this layer handles all interactions with the local SQLite storage:

  • Dual-Model Pattern: Employs Pydantic models for compile-time validation, while maintaining pure Python dataclass fallbacks for Android environments where C-extensions may be restricted.
  • Repository Pattern: StudentRepository, SessionRepository, and UserRepository encapsulate all SQL queries, automatic encryption of sensitive fields, and change queue logging.
  • DatabaseContext: Provides connection pooling, ensures foreign key enforcement (PRAGMA foreign_keys = ON), and injects cryptography providers.

5. Navigation Stack & Anti-Race Controller

Android Gesture Navigation Race Solution
On mobile devices (notably Android 13/14), rapid edge-swipe back gestures can trigger multiple asynchronous route transitions within milliseconds, which previously caused blank screens due to stack desynchronization.

MotorMeasure Pro resolves this through an internal re-entrant navigation lock (self._nav_lock) in GMFMApp. When a route transition begins, subsequent requests are discarded or deferred until the active ft.View tree has committed and updated the display buffer.
