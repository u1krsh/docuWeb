Scoring Engine & Mathematical Formulation

Formal Implementation
The scoring algorithm is implemented in src/gmfm_app/scoring/engine.py. It is a stateless, pure functional calculation that computes domain percentages and overall scores from an input dictionary of item ratings.

1. Mathematical Formula for Domain Scores

For each motor dimension \( d \in \{A, B, C, D, E\} \), let \( I_d \) denote the set of item identifiers belonging to that dimension, and let \( s_i \in \{0, 1, 2, 3\} \) represent the clinician's assigned score for item \( i \).

Let \( S_d = I_d \cap ext{keys}( ext{raw\_scores}) \) denote the subset of items that were actively scored by the assessor. The percentage score for dimension \( d \) is formulated as:

FormulaDimension Percentage
                     ∑_{i ∈ S_d} s_i
Percent(d) = -----------------------------  × 100%
              |S_d| × MAX_ITEM_SCORE (3)

If no items in dimension \( d \) were tested (\( |S_d| = 0 \)), \( ext{Percent}(d) \) resolves defensively to 0.0%.

2. Total Score Formulation

The total GMFM-88 score represents the weighted aggregate across all five motor dimensions. Rather than taking an unweighted average of percentages (which would bias toward smaller domains like Standing), the engine sums the raw observed points across all tested items and divides by the maximum possible score for all evaluated items:

FormulaOverall Total Percentage
                    ∑_{d} ( ∑_{i ∈ S_d} s_i )
Total Percent = ---------------------------------  × 100%
                 ∑_{d} ( |I_d| × MAX_ITEM_SCORE )

3. Missing Items & Not Tested (NT) Policy

Critical Missing Data Rule
Items marked NT (Not Tested) or omitted in raw_scores are strictly excluded from the domain denominator. They are NOT treated as score 0.

Clinically, treating an unattempted item as score 0 (which denotes complete inability to initiate) would artificially depress the child's score for items omitted due to time constraints. The engine reports both n_items_scored and n_items_total for every domain, enabling clinicians and audit reports to immediately identify partial assessments.

4. Engine Implementation Code

src/gmfm_app/scoring/engine.pyCore Engine Method
from typing import Dict, Iterable, Tuple
from gmfm_app.scoring.constants import GMFM88_ITEMS, MAX_ITEM_SCORE

def _score_domain(item_ids: Iterable[int], raw_scores: Dict[int, int]) -> Tuple[float, int]:
    item_ids = list(item_ids)
    if not item_ids:
        return 0.0, 0
    total = 0
    count = 0
    for iid in item_ids:
        if iid in raw_scores:
            val = raw_scores[iid]
            # Defensive clamp between 0 and 3
            val = max(0, min(MAX_ITEM_SCORE, int(val)))
            total += val
            count += 1
    if count == 0:
        return 0.0, len(item_ids)
    max_possible = count * MAX_ITEM_SCORE
    percent = (total / max_possible) * 100.0
    return percent, count
