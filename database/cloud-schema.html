Supabase PostgreSQL Schema & Row Level Security

Production Cloud Schema
The cloud schema is defined in supabase_schema.sql and executed in Supabase's PostgreSQL engine. It establishes a multi-tenant clinical data store with strict Row-Level Security (RLS) enforcement.
Document Contents
  • 1. Cloud PostgreSQL Tables
  • 2. Breaking RLS Recursion with Security Definers

1. Cloud PostgreSQL Tables

Cloud records store both their remote PostgreSQL UUID/Identity and their originating local_id (SQLite ID) along with created_by (Supabase Auth UID):

PostgreSQL DDLSupabase Schema
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  username TEXT UNIQUE,
  full_name TEXT NOT NULL DEFAULT '',
  role TEXT NOT NULL DEFAULT 'teacher', -- 'admin'|'teacher'|'parent'|'sponsor'
  email TEXT NOT NULL DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE students (
  id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  created_by UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  local_id INTEGER NOT NULL,
  given_name TEXT DEFAULT '',
  family_name TEXT DEFAULT '',
  dob TEXT,
  identifier TEXT,
  deleted BOOLEAN DEFAULT FALSE,       -- Soft delete marker
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(created_by, local_id)
);

CREATE TABLE sessions (
  id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  created_by UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  local_id INTEGER NOT NULL,
  student_local_id INTEGER NOT NULL DEFAULT 0,
  scale TEXT DEFAULT '88',
  raw_scores TEXT DEFAULT '{}',
  total_score REAL DEFAULT 0,
  notes TEXT,
  deleted BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(created_by, local_id)
);

CREATE TABLE student_access (
  id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  student_id BIGINT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  access_level TEXT NOT NULL DEFAULT 'view',
  granted_by UUID REFERENCES profiles(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(student_id, user_id)
);

2. Breaking RLS Recursion with Security Definers

Infinite Recursion Prevention
In PostgreSQL, when Table A's RLS policy queries Table B, and Table B's policy queries Table A, PostgreSQL halts queries with an infinite recursion error.

MotorMeasure Pro resolves this by declaring all access evaluation helpers with SECURITY DEFINER STABLE. This executes the check under the database owner's privileges, bypassing RLS during policy evaluation:

PostgreSQL FunctionsSecurity Definer Helpers
CREATE OR REPLACE FUNCTION is_admin()
RETURNS BOOLEAN AS $$
  SELECT EXISTS (
    SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'
  );
$$ LANGUAGE sql SECURITY DEFINER STABLE;

CREATE OR REPLACE FUNCTION user_has_student_access(p_student_id BIGINT)
RETURNS BOOLEAN AS $$
  SELECT EXISTS (
    SELECT 1 FROM student_access WHERE student_id = p_student_id AND user_id = auth.uid()
  );
$$ LANGUAGE sql SECURITY DEFINER STABLE;

CREATE OR REPLACE FUNCTION user_owns_student(p_student_id BIGINT)
RETURNS BOOLEAN AS $$
  SELECT EXISTS (
    SELECT 1 FROM students WHERE id = p_student_id AND created_by = auth.uid()
  );
$$ LANGUAGE sql SECURITY DEFINER STABLE;

4. Cloud Role Protection Trigger

To prevent malicious privilege escalation (e.g. a teacher account submitting a PATCH request altering their role to admin), a PostgreSQL trigger intercepts all mutations on profiles:

PostgreSQL Triggerprotect_profile_role()
CREATE OR REPLACE FUNCTION protect_profile_role()
RETURNS TRIGGER AS $$
BEGIN
  IF TG_OP = 'INSERT' THEN
    IF NEW.role NOT IN ('admin', 'teacher', 'parent', 'sponsor') THEN
      NEW.role := 'teacher';
    END IF;
  ELSIF TG_OP = 'UPDATE' THEN
    -- Only an existing admin may alter another profile's role
    IF NEW.role IS DISTINCT FROM OLD.role AND NOT is_admin() THEN
      NEW.role := OLD.role;
    END IF;
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
