Local SQLite Schema Specification

The local SQLite database (default file: gmfm_app.db) contains seven relational tables structured to support clinical assessments, offline change auditing, and local credential authentication.

Document Contents
  • 1. Table: students
  • 2. Table: sessions
  • 3. Table: app_users
  • 4. Table: student_access
  • 5. Table: sync_queue
  • 6. Tables: sync_metadata & settings

1. Table: students

Stores patient profiles. Identifiable personal data is Fernet-encrypted before write:

SQLite DDLstudents
CREATE TABLE IF NOT EXISTS students (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    given_name  TEXT NOT NULL,      -- Encrypted with Fernet (AES-128-CBC)
    family_name TEXT NOT NULL,      -- Encrypted with Fernet (AES-128-CBC)
    dob         TEXT,               -- ISO 8601 Date (YYYY-MM-DD)
    identifier  TEXT,               -- Encrypted Medical Record Number
    user_id     INTEGER NOT NULL DEFAULT 1,  -- Owning teacher account ID
    created_at  TEXT NOT NULL       -- ISO 8601 UTC string
);

2. Table: sessions

Stores individual clinical assessment encounters and raw scoring payloads:

SQLite DDLsessions
CREATE TABLE IF NOT EXISTS sessions (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id  INTEGER NOT NULL,   -- Foreign Key -> students(id)
    scale       TEXT NOT NULL,      -- '88' or '66'
    raw_scores  TEXT NOT NULL,      -- JSON dictionary: {"1": 3, "2": 0, ...}
    total_score REAL NOT NULL,      -- Calculated total percentage (0.0 - 100.0)
    notes       TEXT,               -- Qualitative clinical observations
    user_id     INTEGER NOT NULL DEFAULT 1,  -- Administering clinician
    created_at  TEXT NOT NULL,      -- Assessment timestamp
    FOREIGN KEY(student_id) REFERENCES students(id)
);

3. Table: app_users

Local credential store for offline login:

SQLite DDLapp_users
CREATE TABLE IF NOT EXISTS app_users (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    username      TEXT NOT NULL UNIQUE, -- Normalized to lowercase
    password_hash TEXT NOT NULL,        -- pbkdf2_sha256$200000$salt$digest
    full_name     TEXT NOT NULL,        -- Clinician display name
    role          TEXT NOT NULL DEFAULT 'teacher', -- 'admin'|'teacher'|'parent'|'sponsor'
    is_active     INTEGER NOT NULL DEFAULT 1,      -- Boolean 1=Active, 0=Disabled
    email         TEXT DEFAULT '',      -- Cloud Supabase identity
    cloud_uid     TEXT DEFAULT '',      -- Supabase Auth UUID
    created_at    TEXT NOT NULL
);

4. Table: student_access

Unified relationship table binding user accounts to specific student profiles with granular permissions:

SQLite DDLstudent_access
CREATE TABLE IF NOT EXISTS student_access (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id   INTEGER NOT NULL,    -- Foreign Key -> students(id)
    user_id      INTEGER NOT NULL,    -- Foreign Key -> app_users(id)
    access_level TEXT NOT NULL DEFAULT 'view', -- 'owner' | 'edit' | 'view'
    granted_by   INTEGER,
    created_at   TEXT NOT NULL,
    FOREIGN KEY(student_id) REFERENCES students(id),
    UNIQUE(student_id, user_id)
);

5. Table: sync_queue

The transaction log powering the offline-first sync engine:

SQLite DDLsync_queue
CREATE TABLE IF NOT EXISTS sync_queue (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    table_name TEXT NOT NULL,         -- 'students' or 'sessions'
    record_id  INTEGER NOT NULL,      -- Local primary key of modified record
    operation  TEXT NOT NULL,         -- 'INSERT', 'UPDATE', or 'DELETE'
    payload    TEXT NOT NULL,         -- Full JSON serialized record state
    created_at TEXT NOT NULL,         -- Timestamp when mutation occurred
    synced     INTEGER DEFAULT 0      -- 0 = Pending Push, 1 = Synced to Cloud
);

6. Tables: sync_metadata & settings

SQLite DDLKey-Value Stores
CREATE TABLE IF NOT EXISTS sync_metadata (
    key   TEXT PRIMARY KEY,           -- e.g. 'last_pull'
    value TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS settings (
    key   TEXT PRIMARY KEY,           -- e.g. 'theme_mode', 'clinic_name'
    value TEXT NOT NULL
);
