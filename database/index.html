Database Architecture Overview

Dual Database Topology
MotorMeasure Pro couples an embedded local SQLite store with an optional cloud PostgreSQL backend on Supabase. This provides immediate offline access on edge devices while enabling collaborative cloud synchronization.
Document Contents
  • 1. Local-to-Cloud Database Topology
  • 2. Multi-Platform SQLite Path Resolution
  • 3. Database Documentation Manuals

1. Local-to-Cloud Database Topology

The system avoids direct networked database drivers (e.g. connecting directly over psycopg2 to Postgres). Instead, the mobile/desktop app interacts exclusively with an embedded SQLite database. All cloud synchronization occurs via HTTPS REST APIs managed by the SyncService:

2. Multi-Platform SQLite Path Resolution

Finding a reliable writable path for SQLite across Android, iOS, Windows, macOS, and Linux requires defensive fallback logic, implemented in resolve_db_path():

src/gmfm_app/data/database.pyPath Resolution Waterfall
def resolve_db_path(explicit: Optional[str] = None) -> Path:
    if explicit:
        return Path(explicit).expanduser().resolve()
    
    # 1. On Android/iOS, check FLET_APP_STORAGE_DATA (isolated app storage)
    flet_storage = os.getenv("FLET_APP_STORAGE_DATA")
    if flet_storage:
        app_dir = Path(flet_storage) / ".gmfm_data"
        try:
            app_dir.mkdir(parents=True, exist_ok=True)
            return app_dir / APP_DB_NAME
        except Exception:
            pass
    
    # 2. Desktop standard: Path.home() / .gmfm_app
    try:
        home = Path.home()
        app_dir = home / ".gmfm_app"
        app_dir.mkdir(parents=True, exist_ok=True)
        return app_dir / APP_DB_NAME
    except Exception:
        # 3. Emergency fallback to Current Working Directory
        app_dir = Path(".") / ".gmfm_data"
        app_dir.mkdir(parents=True, exist_ok=True)
        return app_dir / APP_DB_NAME
