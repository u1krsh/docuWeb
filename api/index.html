Comprehensive Package & Module API Reference

This reference documents the public functions, classes, methods, and constants across the MotorMeasure Pro codebase.

Document Contents
  • 1. Module: gmfm_app.main
  • 2. Module: gmfm_app.scoring.engine
  • 3. Module: gmfm_app.data.database & repositories
  • 4. Modules: gmfm_app.services.*
  • 5. Module: gmfm_app.theme

1. Module: gmfm_app.main

main(page: ft.Page) -> None
Application bootloader. Detects mobile vs desktop runtimes, displays animated brand splash, initializes DatabaseContext, and attaches the master GMFMApp controller.
class GMFMApp(page: ft.Page, db_context: DatabaseContext = None)
Central presentation controller managing URL route changes, view stack instantiation, authentication gating, client storage, and background sync worker lifecycle.

2. Module: gmfm_app.scoring.engine

calculate_gmfm_scores(raw_scores: Dict[int, int], scale: str = "88") -> Dict[str, object]
Computes domain percentages and overall total percentage from raw score dictionary. Returns structured dictionary containing scale, domains, total_percent, items_scored, and items_total.
calculate_gmfm88(raw_scores: Dict[int, int]) -> Dict[str, object]
Convenience wrapper defaulting to GMFM-88 scale evaluation.

3. Module: gmfm_app.data.database & repositories

class DatabaseContext(db_path: str = None, security: SecurityProvider = None)
Encapsulates SQLite connection management, transaction context generation, and symmetric field cipher delegation.
class StudentRepository(BaseRepository)
Methods: list_students(limit=50), get_student(student_id), create_student(student), update_student(student), delete_student(student_id).
class SessionRepository(BaseRepository)
Methods: create_session(session), get_session(session_id), list_sessions_for_student(student_id), get_recent_sessions(limit=3), get_dashboard_stats().

4. Modules: gmfm_app.services.*

class AuthService(db_context, sync_service=None)
Methods: login(page, username, password), create_user_account(...), current_user(page), logout(page), request_password_reset(email), complete_password_reset(page, email, token, new_password).
class SyncService(db_context, config: SyncConfig)
Methods: push() -> SyncResult, pull() -> SyncResult, sync() -> SyncResult, is_online() -> bool, ensure_auth() -> bool, restore_from_cloud() -> SyncResult.
generate_report(student, session, scoring_result, output_path, trend_chart=None, tester_name=None) -> Path
Selects optimal PDF backend (ReportLab, fpdf2, or raw byte generator) and writes clinical PDF report to disk.

5. Module: gmfm_app.theme

get_colors(is_dark: bool) -> dict
Returns design tokens: BG, CARD, BORDER, TEXT1, TEXT2, TEXT3.
DOMAIN_COLORS: Dict[str, str]
Functional color mapping for motor dimensions A through E.
