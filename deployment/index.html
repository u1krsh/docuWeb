Deployment, Android Packaging & Distribution

Cross-Platform Distribution
MotorMeasure Pro is deployed across Android devices, iOS tablets, and desktop workstations from a single Python codebase using the Flet build toolchain.
Document Contents
  • 1. Android APK Build Pipeline
  • 2. Serious Python Runtime & Base64 Asset Strategy
  • 3. Desktop Execution & PyInstaller Packaging

1. Android APK Build Pipeline

To compile a standalone Android APK without requiring external web servers:

TerminalFlet Android Compilation
# Build release APK
flet build apk   --product "MotorMeasure"   --project "MotorMeasure"   --org "com.motormeasure"   --target src/gmfm_app/main.py   --verbose

# Sideload to connected Android device via ADB
adb install -r src/build/apk/app-release.apk

2. Serious Python Runtime & Base64 Asset Strategy

Android Asset Loading Engineering
In Android APK packages using the Serious Python embedder, traditional local file paths (e.g. src/logos/logo.png) frequently fail to resolve due to virtual archive extraction boundaries.

MotorMeasure Pro resolves this through an embedded base64 asset strategy in src/gmfm_app/splash_assets.py (~1 MB). Partner university logos and application emblems are encoded directly as Python string constants (LOGO1_B64, LOGO2_B64, APP_IMG_B64), guaranteeing zero-latency splash rendering on any Android device.

3. Desktop Execution & PyInstaller Packaging

For Windows workstations, the repository includes MotorMeasure_Pro.spec for PyInstaller packaging:

TerminalDesktop Executable Build
# Build standalone Windows executable
pyinstaller MotorMeasure_Pro.spec --noconfirm
