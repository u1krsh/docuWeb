Repositories & Scoped Query Execution

Data Access Abstraction
All SQLite queries are isolated inside specialized repositories in src/gmfm_app/data/repositories.py. Repositories enforce role scoping, automatic encryption/decryption, and change queue auditing.

1. BaseRepository & Scoping Predicates

Every repository inherits from BaseRepository, which dynamically constructs SQL WHERE clauses to enforce data isolation:

src/gmfm_app/data/repositories.pyBaseRepository Scoping
class BaseRepository:
    def __init__(self, db_context=None, user_id=None, visible_ids=None,
                 can_write=True, unrestricted=False):
        self.db_context = db_context or DatabaseContext()
        self.user_id = user_id
        self.visible_ids = visible_ids  # Set of permitted student IDs
        self.can_write = can_write      # False for parent / sponsor
        self.unrestricted = unrestricted # True only for admin

    def _student_scope(self, col: str = "id", owner_col: str = "user_id"):
        if self.unrestricted:
            return "1 = 1", []
        if self.visible_ids is not None:
            if not self.visible_ids:
                return "0 = 1", []
            marks = ",".join("?" * len(self.visible_ids))
            return f"{col} IN ({marks})", list(self.visible_ids)
        if self.user_id is not None:
            return f"{owner_col} = ?", [self.user_id]
        return "1 = 1", []

    def _require_write(self) -> None:
        if not self.can_write:
            raise PermissionError("This account has read-only access")

2. StudentRepository Methods

Method SignatureAction Performed
list_students(limit=50) -> List[Student] Retrieves students permitted within the caller's scope, ordered by creation date descending. Decrypts PII fields.
get_student(student_id: int) -> Optional[Student] Retrieves and decrypts a single student by primary key if permitted by scope.
create_student(student: Student) -> Student Enforces _require_write(), encrypts PII fields, inserts student, creates owner access link in student_access, and logs an INSERT to sync_queue.
update_student(student: Student) -> Student Re-encrypts updated PII fields, commits UPDATE within scope, and logs mutation to sync_queue.
delete_student(student_id: int) -> None Deletes student record, cascades deletions across student_access, and logs a DELETE tombstone to sync_queue.

3. SessionRepository Methods

Method SignatureAction Performed
create_session(session: Session) -> Session Serializes raw score dictionary to JSON, inserts into sessions, and logs INSERT to sync_queue.
get_session(session_id: int) -> Optional[Session] Retrieves session within student scope and unpacks JSON raw scores into integer dictionary.
list_sessions_for_student(student_id: int) -> List[Session] Returns all longitudinal assessment sessions for a specific child, sorted newest first.
get_recent_sessions(limit: int = 3) -> List[dict] Executes an optimized JOIN between sessions and students to populate the dashboard with recent evaluations.
get_dashboard_stats() -> dict Calculates total session counts and overall average score across visible students in a single SQL aggregation.

4. UserRepository Methods

Provides identity lookups for local authentication:

  • count_users() -> int: Used during initialization to bootstrap the very first registered user as admin.
  • get_by_username(username: str) -> Optional[AppUser]: Normalizes username to lowercase and returns credential hash.
  • get_by_email(email: str) -> Optional[AppUser]: Resolves user for cloud synchronization and password reset.
  • update_role(user_id: int, role: str) -> None: Reconciles local user role after cloud sign-in.
  • update_cloud_uid(user_id: int, cloud_uid: str) -> None: Binds a local user ID to a Supabase UUID.

5. Transaction Sync Logging (_log_sync)

Whenever a repository commits a state change, it invokes _log_sync() within the active database transaction:

src/gmfm_app/data/repositories.pyAudit Logging Function
def _log_sync(conn, table_name: str, record_id: int, operation: str, payload: dict):
    try:
        conn.cursor().execute(
            '''INSERT INTO sync_queue 
               (table_name, record_id, operation, payload, created_at, synced) 
               VALUES (?, ?, ?, ?, ?, 0)''',
            (table_name, record_id, operation, json.dumps(payload), datetime.utcnow().isoformat())
        )
    except Exception:
        # Failure in audit logging must not abort the primary clinical write
        pass
