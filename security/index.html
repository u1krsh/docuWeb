Security, Cryptography & Threat Mitigation

Healthcare Privacy Standards
MotorMeasure Pro manages pediatric medical and developmental data. The security subsystem (src/gmfm_app/services/security.py) enforces field-level cryptography at rest, secure password hashing, and fail-closed data scoping.
Document Contents

  • 2. Cryptographic Key Resolution Chain

1. Fernet Symmetric Field-Level Encryption

Personal identifiable information (PII) is encrypted before being written to SQLite using Fernet symmetric encryption (from the cryptography library). Under the hood, Fernet uses:

  • AES-128-CBC for confidentiality.
  • HMAC-SHA256 for message authentication and integrity verification.
  • 128-bit initialization vector (IV) generated per write using os.urandom().

Fields encrypted in the local database: students.given_name, students.family_name, and students.identifier (Medical Record Number).

2. Cryptographic Key Resolution Chain

The SecurityProvider resolves the master encryption key following a 3-stage priority waterfall:

src/gmfm_app/services/security.pyKey Resolution Waterfall
def _load_key(self) -> bytes:
    # 1. Environment Variable: GMFM_APP_SECRET (Highest Priority)
    env_key = os.getenv("GMFM_APP_SECRET")
    if env_key:
        return env_key.encode()

    # 2. Local Key File: .gmfm_key in application data directory
    file_key = self._read_local_key()
    if file_key:
        return file_key

    # 3. Dynamic Generation: Generate new Fernet key and persist locally
    new_key = Fernet.generate_key()
    self._persist_key(new_key)
    return new_key

3. Threat Model & Countermeasures

Threat VectorPotential ImpactMitigation Architecture
Physical Device Theft Extraction of raw SQLite file from device flash storage. Patient names and medical record numbers are stored as Fernet ciphertext. Unreadable without master key.
Local Credential Extraction Offline dictionary attack against clinician passwords. PBKDF2-HMAC-SHA256 with 200,000 iterations and 16-byte random salt prevents rainbow table attacks.
Unauthorized Cloud Snooping API interception of student assessments. Supabase PostgreSQL enforces Row-Level Security (RLS). Users can only select records they created or were explicitly granted access to.
Privilege Escalation A teacher altering their role to admin via cloud API. PostgreSQL trigger protect_profile_role() intercepts UPDATE statements and rejects non-admin role modifications.
