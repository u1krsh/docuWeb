The MotorMeasure Pro Documentation

Project Purpose & Scope
MotorMeasure Pro (repository: GMFM_System88) is an offline-first, cross-platform clinical assessment application that digitizes the Gross Motor Function Measure (GMFM-88 / GMFM-66) scoring protocol. It is engineered specifically for physiotherapists, clinicians, occupational therapists, educators, and rehabilitation centers working with children with cerebral palsy and other motor disabilities.

This documentation manual is formatted in the technical style of docs.kernel.org. It serves as the definitive reference for the system architecture, mathematical scoring formulation, offline-to-cloud synchronization engine, cryptography subsystem, database schemas, and developer APIs.

1. Executive Summary & Clinical Context

The Gross Motor Function Measure (GMFM) is the internationally recognized gold standard clinical evaluation tool for assessing motor skill execution in pediatric rehabilitation. Historically, assessments have been recorded manually on paper score sheets, leading to significant administrative friction:

  • Repeated manual entry of patient identifiable information across paper forms.
  • Manual error-prone score summation across 88 individual criteria across 5 complex motor dimensions.
  • Calculation of per-domain percentages and weighted total scores by hand or auxiliary spreadsheets.
  • Difficulty tracking longitudinal motor trajectories across multi-year rehabilitation intervals.
  • Absence of structured multi-role visibility for multidisciplinary teams (clinicians, school educators, parents, and healthcare sponsors).

MotorMeasure Pro provides an end-to-end digital clinical workflow that eliminates paper-based errors while strictly preserving clinical fidelity. Most importantly, it is built with an offline-first architecture, guaranteeing full assessment functionality in remote clinics, rural rehabilitation centers, or schools without internet access.

2. Quick Start & Execution Commands

The application runs on Android, iOS, Windows, macOS, and Linux from a single unified Python and Flet codebase.

Terminal / Command PromptSetup & Run
# 1. Clone repository
git clone https://github.com/yourusername/GMFM_System88.git
cd GMFM_System88

# 2. Setup virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

# 3. Install dependencies
pip install -r src/requirements.txt

# 4. Launch desktop development runtime
python -m gmfm_app.main

# 5. Build native Android APK (Flet build)
flet build apk --product MotorMeasure --project MotorMeasure --org com.motormeasure --target src/gmfm_app/main.py

Current Release v0.0.3 (Production Hardened)
Lead Architect / Author Uttkarsh Singh
Programming Language Python 3.11+
UI Framework Flet 0.28.3 (Flutter native rendering engine)
Primary Local Storage SQLite 3 (via standard library sqlite3, connection pooling with DatabaseContext)
Optional Cloud Backend Supabase (PostgreSQL 15+, GoTrue Auth, Row Level Security)
Assessment Families GMFM-88 (88 items) and GMFM-66 (subset scale)
At-Rest Encryption Fernet (AES-128-CBC + HMAC-SHA256, cryptography library)
Local Password Hashing PBKDF2-HMAC-SHA256 (200,000 iterations, 16-byte cryptographically secure salt)
PDF Generation Engine 3-Tier Fallback: ReportLab → fpdf2 → Custom Pure-Python Raw Byte Generator
Target Operating Systems Android 8.0+ (ARM64/x86_64), iOS 14+, Windows 10/11, macOS, Linux
